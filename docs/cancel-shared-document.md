# How to Cancel a Shared Document?

Sometimes, after sharing a document, you may need to **cancel or revoke access** — for example, if the wrong recipient was added or the document content has changed.  
Doculan allows you to **cancel shared documents instantly**, preventing any further access or activity.

---

##  Overview

Cancelling a shared document:
- Immediately **revokes access** for all recipients.  
- Prevents further downloads, views, or sharing.  
- Updates the document status to **Cancelled**.  
- Keeps the original audit trail for record-keeping.

>  Once cancelled, the document cannot be reopened or signed unless resent as a new document.

---

##  Step-by-Step: Cancelling a Shared Document

<details>
  <summary><b>Step 1: Navigate to your shared folder</b></summary>

- Log in to **Doculan** and open your **Dashboard**.  
- Locate the folder that contains the document you shared — usually named *e-sign documents* or *Shared Contracts*.  
- A table will display all your documents with details like *Name*, *Party Details*, *Last Modified*, *Status*, and *Actions*.

> 🖼️ **Screenshot Placeholder:** Folder view showing shared documents and their statuses.
</details>

---

<details>
  <summary><b>Step 2: Identify the document to cancel</b></summary>

- Look for the document currently marked as **Shared**, **Active**, or **In Progress**.  
- These are eligible for cancellation.  
- You can verify recipient activity (viewed/unopened) by clicking the **Audit** button.

> 🖼️ **Screenshot Placeholder:** Audit trail showing shared activity before cancellation.
</details>

---

<details>
  <summary><b>Step 3: Open the Actions menu</b></summary>

- In the **Actions** column, click the **three-dot (⋮)** button for the specific document.  
- The dropdown menu will show several options — *View*, *E-Sign*, *Share*, *Download*, *Delete*.  
- Select **Cancel** (or **Cancel Share**, depending on interface).

> 🖼️ **Screenshot Placeholder:** Actions dropdown showing Cancel/Cancel Share option.
</details>

---

<details>
  <summary><b>Step 4: Confirm cancellation</b></summary>

A confirmation popup appears with details of the document name and recipients.

- Review the message:  
  _“Are you sure you want to cancel sharing this document? Recipients will no longer have access.”_  
- Click **Yes / Confirm** to proceed.

> 🖼️ **Screenshot Placeholder:** Confirmation dialog box for cancelling a share.
</details>

---

<details>
  <summary><b>Step 5: Verify the cancellation</b></summary>

After confirming:
- The document’s **Status** immediately changes to **Cancelled**.  
- All previously shared links become **invalid**.  
- Recipients who attempt to open the link will see a message:  
  _“Access revoked — this document is no longer available.”_

> 🖼️ **Screenshot Placeholder:** Dashboard showing document with Cancelled status.
</details>

---

##  Example Scenario

You shared a contract with a vendor but later realized an outdated version was sent.  
Here’s what you do:

1. Open your folder → locate the shared document.  
2. Click **⋮ → Cancel Share**.  
3. Confirm the cancellation.  
4. Status changes to **Cancelled**.  
5. Upload and resend the updated version using **Share** again.

---

##  Notes & Limitations

| Condition | Action | Result |
|------------|---------|--------|
| Shared/Active |  Can cancel | Revokes all access |
| Completed |  Cannot cancel | Document already signed |
| Cancelled | — | Already revoked |
| Expired |  No need to cancel | Link already invalid |
| Audit Trail | Always available | Shows cancellation timestamp |

---

##  Best Practices

-  Cancel immediately if a wrong recipient was added.  
-  Keep the cancelled record for compliance.  
-  Always resend a **new** share link after editing or updating content.  
-  Remember: cancellation is permanent and cannot be undone.  
-  Inform the recipient via email if a cancellation was unintentional.
