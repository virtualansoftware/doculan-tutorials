# How to Use Anonymous VDR?

**Anonymous VDR** allows you to securely share documents and folders with external users without requiring them to create a Doculan account. You can create an anonymous access link, configure security settings such as passwords and expiration dates, and share the link with authorized recipients.

---

### 1. Select and Add a Folder to the VDR

- Navigate to the documents and select the appropriate folder.
- Open the folder action menu and click **Share Folder**.

<img src="screenshots\VDR\Select Folder.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="Screenshot for Document"><br>

- The **Folder Added to VDR** popup will appear; click **Go to VDR** to continue.

<img src="screenshots\VDR\Goto VDR.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="Screenshot for Document">

---

### 2. Configure Secure Access

After selecting the **Anonymous VDR** option, configure the public link settings to control how external users access the shared folder.

1. **Set the Expiry Date**

   * Select an **Expiry date** for the sharing link.
   * The link will remain active until the specified date and time.
   * Enable **Never expire** if you want the link to remain active without an end date.

2. **Ask for Visitor Email**

   * Enable **Ask for visitor email** if you want visitors to provide their email address before accessing the shared folder.
   * This allows visitors to identify themselves when opening the public link.

3. **Allow Downloads**

   * Enable **Allow download** to let visitors download files from the shared folder.
   * Keep this option disabled if visitors should only be able to view the shared files online.

4. **Enable Tiny URL**

   * Enable **Enable Tiny URL** to generate a shorter sharing link instead of the full folder URL.
   * Enter a custom value in the **Alias** field to create a personalized Tiny URL.
   * For example, you can use a meaningful keyword or folder name as the alias.
   * If the Alias field is left blank, the system automatically generates a random Tiny URL.

5. **Create the Public Link**

   * Review the configured link settings.
   * Click **Create public link** to generate the sharing URL.
   * The generated URL can then be copied and shared with external users.


<img src="screenshots\VDR\Anonymous VDR Configuration.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="Screenshot for Document"><br>

<img src="screenshots\VDR\Tiny URL Configuration.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="Screenshot for Document">

> **Note:** Anonymous VDR supports both the standard **Full URL** and **Tiny URL**. When Tiny URL is enabled, you can optionally customize the URL using an alias, making the link easier to recognize and share.

---

### 3. Generate the Sharing URL

Anonymous VDR provides two URL options for sharing the folder:

**Full URL:** Generate and share the complete anonymous VDR link.

<img src="screenshots\VDR\Full URL.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="Screenshot for Document">

**Tiny URL:** Generate a shorter sharing link that is easier to copy, share, and communicate.

<img src="screenshots\VDR\Tiny URL.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="Screenshot for Document">

> For the Tiny URL, you can customize the URL with a preferred name or keyword, making the link easier to recognize and remember.

---

### 4. Share the URL
- Copy the generated Full URL or Tiny URL.
- Share the link with the intended external users.
- Recipients can access the shared folder through the URL without requiring a Doculan account.
- If password protection is enabled, recipients must enter the configured password before accessing the shared content.


---

### 5. Access the Shared Folder

- The recipient opens the secure share link.
- The recipient can then access the documents according to the permissions configured for the shared folder.

<img src="screenshots\VDR\VDR Access Link.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="Screenshot for Document"><br>

---

### 6. Manage Anonymous Access

- Return to the VDR to review the shared folder and its access settings.
- You can update the security settings or disable the secure share link when access is no longer required.

<img src="screenshots\VDR\Disable Link.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="Screenshot for Document">

> **Note:** Anonymous VDR is useful when you need to share confidential documents with external users while maintaining control over access through secure links, passwords, expiration settings, and permissions.
