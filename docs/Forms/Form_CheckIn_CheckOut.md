# How to Use QR Check-In and Check-Out in a Form?

The **QR Check-In and Check-Out** feature allows users to access a form by scanning a QR code and record their check-in and check-out activity. This provides a convenient way to manage attendance, visits, or user sessions without requiring manual entry.

# Step 1: Open the Form

- Navigate to the Forms section.
- Locate the required form.
- Open the Action Menu for the form.
- Select Check IN.

## Step 2: Fill and Submit the  Form

- The users opens the public form link or scans the QR code.

### QR Code Display

After adding the QR Code Field:

* The QR code is displayed directly on the form.
* A sample QR code is shown before the form is submitted.
* After submitting the form, the original QR code is generated and made available for use.
* Users can scan the generated QR code for quick access to the associated information.

### CAPTCHA Verification

If CAPTCHA verification is enabled, users must enter the displayed CAPTCHA code before submitting the form.

### Submit the Form

After completing the required fields and verification, click **Submit** to submit the form and generate the final QR code.

<img src="screenshots\CheckIn_CheckOut\Form_Fill.png" alt="Step 2 — view all Docs" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;"><br>

## Step 3: Successful Submission

### QR Code Generation After Submission

After the form is submitted successfully, the **QR Code Field** generates the final QR code automatically.

* A **Submitted Successfully!** message confirms that the form response has been recorded.
* The generated QR code is displayed on the confirmation page.
* Click **Download QR Code** to save the QR code to your device.
* The downloaded QR code can be scanned using a mobile device to access the associated information.

# Step 4: Review Form Details

- Navigate to the **Forms** section and open the required anonymous form.
- Select the **Action Menu**
- Click the **Check IN**

<img src="screenshots\CheckIn_CheckOut\Form_Check_IN.png" alt="Step 2 — view all Docs" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;"><br>

### Scan QR Code for Check-In

The **Scan to Check-in** feature allows staff to check in a participant by scanning their QR code.

* Click **Scan to Check-in** to open the QR code scanner.
* Allow **camera access** when prompted by the browser.
* Position the participant’s QR code within the scanner to scan it.
* If a camera is not available, click **Upload QR Code Image** to select a QR code image from your device.
* Once the QR code is successfully scanned, the participant can be checked in.
* Click **Cancel** to close the scanner without completing the check-in.

<img src="screenshots\CheckIn_CheckOut\Form_Upload_QR_Image.png" alt="Step 2 — view all Docs" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;"><br>


### Upload a QR Code Image

The **Scan to Check-in** feature allows users to check in by scanning a QR code or uploading a QR code image.

* Click **Upload QR Code Image**.
* Select the QR code image from your device.
* The system processes the uploaded image and validates the QR code.
* Once the QR code is recognized successfully, the check-in is completed.
* To upload a different QR code, click **Upload Another Image**.
* Click **Cancel** to close the check-in window without uploading an image.

<img src="screenshots\CheckIn_CheckOut\Form_Upload_Image.png" alt="Step 2 — view all Docs" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;"><br>

**Note:** Ensure the uploaded image contains a clear and readable QR code for successful verification.
