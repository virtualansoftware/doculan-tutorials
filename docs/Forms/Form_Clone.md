# ✅ **Steps to Clone the Form**

### Steps:
- Go to **Dashboard → Forms**
- Click **Action → Clone**
- Review & click **Send Form**
- Add recipients again and send
- All the steps are same as like Create and Send Form, We already seen in [How to Create and Send Forms ](Form_Create.md)

> ✅ Forms can be cloned even if they are **Completed, Cancelled, Resent, or Expired**
