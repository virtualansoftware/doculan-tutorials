## E-Sign Template

### What is Myself / Team template

Templates in Doculan help you save time by reusing predefined document field setups.

- **Myself Template** → Personal use only.  
- **Team Template** → Shared with your team for collaboration.

### How to create template

1. Open **E-Sign → Templates → Create New Template**.  
2. Upload a base document.  
3. Drag and drop required fields (Signature, Date, Text Box, etc.).  
4. Save it as **Myself** or **Team** template.

---

### How to update template

1. Navigate to **E-Sign → Templates**.  
2. Select the template you want to edit.  
3. Click **Edit Template**.  
4. Update fields or email text as needed.  
5. Click **Save Changes**.

---

### How to delete template

1. Go to **E-Sign → Templates**.  
2. Select the template you want to delete.  
3. Click the **Delete** icon or button.  
4. Confirm deletion when prompted.
