# How to Update a Template?

Updating a template in **Doculan eSign** allows you to modify existing layouts, fields, or signer configurations — without having to recreate them from scratch.  
It’s perfect when your contracts evolve or you want to add new terms or fields to an existing format.

---

##  Overview

A template update lets you:
- Add or remove fields  
- Modify signer roles or emails  
- Change layout positions of fields  
- Save the new version under the same or a different name  

You can update **Myself** or **Team** templates using the same steps.

---

##  Step-by-Step: Updating an Existing Template

<details>
  <summary><b>Step 1: Open the eSign editor</b></summary>

- From your **Dashboard**, go to your folder (e.g., “e-sign documents”).  
- Locate any document you want to use with the existing template.  
- Click the **three-dot (⋮)** menu under **Actions** → Select **E-Sign**.

> 🖼️ **Screenshot Placeholder:** Dashboard view showing ⋮ → E-Sign menu.
</details>

---

<details>
  <summary><b>Step 2: Load an existing template</b></summary>

- Once the eSign editor opens, navigate to the **Template** tab.  
- From the dropdown list, select the template you wish to modify.  
- The saved layout (fields, parties, and configurations) will automatically load.

> 🖼️ **Screenshot Placeholder:** Template dropdown with existing templates visible.

>  **Tip:** If your desired template isn’t visible, click **Refresh** or reload the page to sync template data.
</details>

---

<details>
  <summary><b>Step 3: Make necessary changes in the Fields tab</b></summary>

- Go to the **Fields** tab to modify your existing field placements.  
- You can drag existing fields to new positions or remove them using the **Delete (🗑️)** icon.  
- Add new fields like:
  - Signature  
  - Text  
  - E-mail  
  - Checkbox  
  - Date  
  - Dropdown  
  - Attachment

> 🖼️ **Screenshot Placeholder:** Field editing with drag and drop adjustments.

>  **Example:**  
If your contract now requires a “Company Seal” field, drag a new **Signature** field labeled “Company Seal” into the document.
</details>

---

<details>
  <summary><b>Step 4: Update party details</b></summary>

- Navigate to the **Parties** tab.  
- Verify all existing signers (Party 1, Party 2, etc.).  
- Click **Add Party** if new signers are needed.  
- Update any incorrect or changed email IDs.  
- You can also reorder or rename parties if necessary.

> 🖼️ **Screenshot Placeholder:** Parties tab showing editable name and email fields.
</details>

---

<details>
  <summary><b>Step 5: Save the updated configuration back to the template</b></summary>

Now that your fields and parties are updated, let’s save the new version.

1. Go back to the **Template** tab.  
2. Click on the **Save Template** button.  
3. Choose:
   - **Same Template Name** → overwrite the existing one, or  
   - **New Template Name** → create a new version.

Example:
- Old Template: `Service_Agreement_v1`
- Updated Template: `Service_Agreement_v2`

> 🖼️ **Screenshot Placeholder:** Save Template popup with editable name field.

>  **Important:** Overwriting will replace the previous template permanently.
</details>

---

<details>
  <summary><b>Step 6: Verify your updated template</b></summary>

- Return to the **Template** dropdown and search for your updated version.  
- Select it to ensure all recent changes (fields, parties, layout) are correctly loaded.  
- Optionally, send a test document using this updated template to confirm it works as intended.

> 🖼️ **Screenshot Placeholder:** Template verification with loaded new layout.
</details>

##  Example Scenario

Let’s say your “NDA Template” originally had two fields:  
- Signature (Party 1)  
- Date  

Now, your workflow requires adding:
- Company Representative Signature (Party 2)  
- Checkbox for “I Agree to Terms”

You can:
1. Load “NDA Template” from the Template tab.  
2. Add Party 2 and their signature field.  
3. Add a Checkbox for acceptance.  
4. Save as “NDA_Template_v2”.  
5. Done — your template is updated.

---

##  What Gets Updated

| Component | Updatable? | Description |
|------------|-------------|-------------|
| Field Layout | ✅ | Add/remove/move any fields |
| Parties | ✅ | Add, edit, or remove signers |
| E-mail Setup | ✅ | Change email subject or body |
| Document File | ⚠️ | Only update if re-uploaded manually |
| Template Type | ❌ | Remains as Myself or Team (same as original) |

##  Tips for Template Management

-  Always version your templates clearly (e.g., `_v2`, `_2025Q1`).  
-  Inform your team when updating shared templates.  
-  Delete obsolete templates to reduce confusion.  
-  Check “Last Modified” date in the Template section to verify freshness.  
-  For sensitive templates, prefer “Myself” visibility.
