# How to Share a Document?

The **Share Document** feature in Doculan allows you to send any stored document to individuals or groups quickly and securely — without requiring them to log in.  
You can share for **review**, **reference**, or **collaboration**, while maintaining full control over access permissions.

---

##  Overview

The **Share** feature provides a simple way to send read-only or editable access to any stored file directly from your dashboard.

It is often used to:
- Share signed contracts or templates with clients.  
- Send drafts for approval or feedback.  
- Collaborate with colleagues without duplicating files.

>  Note: Shared documents are temporary links; recipients can view or download only until access expires.

---

##  Step-by-Step: Sharing a Document

<details>
  <summary><b>Step 1: Navigate to your document folder</b></summary>

- Go to your **Dashboard**.  
- Open the folder where your document is stored (e.g., “e-sign documents” or “Contracts”).  
- You’ll see a table listing your files with columns — Name, Party Details, Last Modified, Created By, Status, and Actions.

> 🖼️ **Screenshot Placeholder:** Dashboard with folder view and document list.
</details>

---

<details>
  <summary><b>Step 2: Access the sharing options</b></summary>

- In the **Actions** column, click the **three-dot (⋮)** button beside the document you want to share.  
- From the dropdown menu, select **Share**.

> 🖼️ **Screenshot Placeholder:** Actions menu showing “Share” option.
</details>

---

<details>
  <summary><b>Step 3: Configure sharing details</b></summary>

Once you click Share, a popup or side panel will appear with fields for:

- **Recipient Name**  
- **Recipient Email Address**  
- **Access Type:**  
  - *View Only* → Recipient can view or download.  
  - *Edit Access* → Recipient can edit content (if enabled).  
- **Expiry Date:** Set how long the link should remain active.  
- **Reminder:** Choose to send an email reminder before expiration.  
- **Message (optional):** Add a personalized message for context.

> 🖼️ **Screenshot Placeholder:** Sharing popup with recipient and expiry options.
</details>

---

<details>
  <summary><b>Step 4: Attach and send the document</b></summary>

- Review all details once again.  
- Optionally, click **AI Assist** to generate a professional message body for your email.  
- Click **Send** to deliver the document.

Recipients will receive an email with a secure link. Clicking it opens the shared document directly in their browser.

> 🖼️ **Screenshot Placeholder:** Email compose popup and Send button.
</details>

---

<details>
  <summary><b>Step 5: Verify and monitor shared status</b></summary>

After sending:
- Go back to your **Dashboard** → select the same folder.  
- Check the **Status** column to view sharing status (e.g., *Shared*, *Viewed*, *Expired*).  
- Click the **Audit** button to see complete tracking details — when it was sent, opened, or downloaded.

>  **Screenshot Placeholder:** Dashboard showing shared status and Audit button.
</details>

---

##  Example Scenario

Imagine you’ve finalized a contract and need to share it with a client for record-keeping.

1. Go to your e-sign folder → locate “Service_Agreement.pdf.”  
2. Click **⋮ → Share**.  
3. Enter recipient details (e.g., `john.doe@company.com`).  
4. Set expiry to **7 days**, add a message — “Please review this document for reference.”  
5. Click **Send**.  
6. The client receives a secure view-only link with an audit trail recorded automatically.

---

##  Important Notes

| Setting | Description | Notes |
|----------|--------------|-------|
| View Only | Recipients can view or download | Recommended for clients |
| Edit Access | Allows modifications | Use cautiously |
| Expiry | Auto-revokes access after set date | Can’t be reopened |
| Reminder | Sends email before expiry | Optional |
| Audit Trail | Tracks every share action | Can be exported as report |

##  Best Practices

-  Always verify recipient email before sending.  
-  Use “View Only” mode for sensitive documents.  
-  Set expiry dates for temporary access.  
-  Use personalized messages for professionalism.  
-  Audit regularly to ensure shared files are accessed responsibly.  
-  Use **AI Assist** to quickly draft formal, error-free emails.
