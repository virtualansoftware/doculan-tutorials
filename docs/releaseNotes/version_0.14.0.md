##  **Virtual Data Room (VDR)**

The **Virtual Data Room (VDR)** is a secure digital workspace for storing, managing, and sharing confidential documents with internal teams and external stakeholders. It provides granular access controls, activity tracking, and secure collaboration features to ensure sensitive information is shared only with authorized users. VDR is ideal for due diligence, mergers and acquisitions, audits, legal transactions, fundraising, and other business processes that require secure document sharing.

## 2️⃣ **Filters**

The **Filters** option helps you quickly locate documents by narrowing the displayed results based on specific criteria. You can filter documents using a **Date Range**, **Document Type**, **Sort By**, and **Sort Order**. This makes it easier to find the exact files you need without manually searching through the entire document list.

**Available Filter Options:**

- **Date Range:** Display documents created or modified within a selected date range.
- **Type:** Filter documents by their type (e.g., All Types, Folder, Document, etc.).
- **Sort By:** Arrange documents based on attributes such as Date Modified.
- **Sort Order:** Display results in Ascending or Descending order.
- **Clear Filters:** Click the × icon to remove all applied filters and restore the default document list.
