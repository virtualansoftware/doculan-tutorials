# 🚀 Version 0.14.3 – New Enhancements

## 1️⃣ **Single-Line Input Fields**

Updated the **Text, Number, Email Address, Date, and Textarea** fields to use a cleaner and more consistent single-line input design. This enhancement provides a streamlined appearance across all supported field types while maintaining their existing functionality and validation behavior.

The new layout improves the overall form presentation by reducing unnecessary input-box styling, providing better visual consistency between fields, and creating a cleaner and more user-friendly form-filling experience.
