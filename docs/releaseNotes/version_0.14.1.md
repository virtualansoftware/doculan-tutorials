# 🚀 Version 0.14.1 – New Enhancements

## 1️⃣ **Form New Rating Field and Information Text Field**

### Form New Rating Field

The **Rating Field** allows users to provide a score or rating within a form. It is commonly used for collecting feedback, customer satisfaction, service quality, product reviews, or survey responses.

**Features:**

- Supports star-based or numeric ratings.
- Configure the minimum and maximum rating values.
- Mark the field as required or optional.
- Add a custom label and placeholder/help text.
- Validate that a rating is selected before form submission (if required).

### Information Text Field

The **Information Text Field** is a non-editable element that allows you to display informative content within a form. It is designed to provide users with instructions, descriptions, announcements, warnings, or other helpful information without requiring any input.

Unlike standard form fields, the Information Text Field does not collect, validate, or store user data. Instead, it enhances the user experience by presenting clear guidance and contextual information at any point in the form.

**Key Features**

- Display instructions, notices, and descriptive text.
- Organize forms with section headings and explanations.
- Present important alerts, warnings, or announcements.
- Does not accept or store user input.
- Customize the appearance using background colors, text styles, borders, and spacing.
- Improve form readability and provide a consistent user experience.

## 2️⃣ **Form Optional Pagination (Single/Multiple)**

The **Form Optional Pagination** feature allows you to control how fields are displayed in your form. By default, forms use the **Multiple Pages** layout, where fields are organized into separate pages for better navigation and readability.

If your form contains more than 10 fields, you can enable the **Single Page** option to display all fields on one page. This eliminates page navigation and allows users to complete the entire form without switching between pages.

**Features**

- Choose between Single Page and Multiple Pages layouts.
- Organize fields into logical sections.
- Improve navigation with Next and Previous buttons.
- Reduce scrolling for long forms.
- Create a cleaner and more user-friendly form experience.

## 3️⃣ **Form Card Background/Cover Background(Theme)**

The **Form Card Background / Cover Background (Theme)** feature allows you to customize the overall appearance of your form by applying backgrounds and themes. You can personalize both the form card, where users enter information, and the cover page, which introduces the form.

Custom backgrounds and themes help create a professional, visually appealing form that aligns with your organization's branding and enhances the user experience.

**Features**

- Apply a custom background color or image to the form card.
- Customize the cover page with a background image or color.
- Choose from available themes to change the form's overall appearance.
- Match the form design with your organization's branding.
- Create a consistent and engaging user experience.

## 4️⃣ **Form Multiple Field Shrink**

The **Form Multiple Field Shrink** feature allows multiple form fields to be displayed on the same row, reducing the space occupied by each field. This helps create a compact and organized form layout while improving readability and minimizing unnecessary scrolling.

You can adjust the width of individual fields so that related fields, such as First Name and Last Name or City, State, and ZIP Code, appear side by side.

**Features**

- Display multiple fields in a single row.
- Adjust field width to create a compact layout.
- Group related fields together for better organization.
- Reduce vertical space and scrolling.
- Improve the overall appearance and usability of the form.

## 5️⃣ **Anonymous Form for Audit Log**

The **Anonymous Form Audit Log** records all activities performed on an anonymous form without collecting or displaying the respondent's identity. It provides a complete history of form-related events, helping administrators monitor form usage, track changes, and maintain transparency while preserving user anonymity.

**Features**

- Records all anonymous form activities.
- Tracks form creation, updates, and submissions.
- Maintains user anonymity throughout the audit process.
- Displays event details, timestamps, and activity history.
- Supports auditing and compliance requirements.
