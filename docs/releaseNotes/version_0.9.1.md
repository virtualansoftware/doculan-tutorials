# 🚀 Version 0.9.1 – New Enhancements

## 1️⃣ Default Date Auto-Fill

**Date fields** are now automatically populated with the current date based on Date Settings configuration. By default, **“Date with Default”** is enabled, but users can deselect these options before **sending documents**.

## 2️⃣ Apply Initials to All Fields

Users can now quickly populate all **initial fields** across a document using the **“Apply All”** option. A confirmation popup is displayed before applying, ensuring consistency and preventing accidental updates.

## 3️⃣ Enhanced Download Options (ZIP / Merge PDF)

Download **signed documents** with improved flexibility—choose to **merge the signed document** and completion certificate into a **single PDF** or download them **separately** as files bundled in a ZIP for easier sharing and storage.
