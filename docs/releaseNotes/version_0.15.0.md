# 🚀 Version 0.15.0 – New Enhancements

## 1️⃣ **Email Layout Customization**

Updated the **Email Layout** feature to support multiple document workflows, including **E-Sign, Form, VDR, Share Document, and Document Review**. Users can select the required module and create a dedicated email layout based on the selected workflow.

Each layout can be managed with **Preview, Edit, and Delete** options, allowing users to easily customize and maintain separate email templates for different document activities. This provides a consistent and professional email experience across all supported modules.

## 2️⃣ **Revoke Completed Document**

Added the **Revoke Document** functionality for completed and signed **E-Sign** contracts. Once a document is successfully completed and signed, the sender can revoke the document when required by providing a mandatory revoke reason.

The revoked document is clearly marked as **REVOKED** and is no longer considered valid, while the original signed document and its signing history remain preserved for **audit and tracking purposes**.

## 3️⃣ **Form Ticket Field**

Added the **Ticket Field** to the Form Builder to support event and ticket-based form submissions. The sender can configure multiple **ticket categories** such as Employee, College Student, and School Student, along with individual ticket prices and descriptions for each category.

The Ticket Field also allows senders to configure **coupon codes** with discount values. On the respondent side, users can select their preferred ticket category, adjust the required quantity, view the ticket description and pricing, and apply an available coupon to see the updated discount and total amount before submitting the form.

**Features:**
- Configure a **ticket name, price, and description** for each ticket category.
- Set the **maximum number of tickets** that can be selected.
- Enable or disable **coupon support** for the ticket field.
- Configure **coupon codes** with discount percentage or fixed discount amounts.
- Allow users to select the required **ticket category and quantity**.
- Automatically calculate the **ticket total, discount, and final amount** based on the selected options.
- Display the configured **ticket details and pricing** clearly on the user side.

## 4️⃣ **Rich Text Support for Email Body**

Added **Rich Text Support** to the email body, allowing users to easily format and customize email content without requiring HTML knowledge. Users can add and edit content with formatting options such as **bold, italic, headings, links, lists, and text alignment**.

The enhanced email editor provides a more flexible and user-friendly way to create professional email content while maintaining consistent formatting across different email layouts and supported workflows.
