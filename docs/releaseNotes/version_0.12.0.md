# 🚀 Version 0.12.0 – New Enhancements

## 1️⃣ **Manage Labels**

The **Manage Labels** feature allows users to create, organize, and manage labels for documents and contracts. Labels help categorize content, improve document organization, and make it easier to search, filter, and identify documents within the system. Users can create custom labels, assign them to documents or contracts, edit existing labels, and remove labels when they are no longer needed. This feature enhances document management and improves overall workflow efficiency.

## 2️⃣ **Add Banner**

The **Add Banner** feature allows administrators to upload and manage a custom banner image for their organization. The banner is displayed in the application header and helps personalize the platform with company branding. Users can upload a new banner, replace an existing banner, or remove the current banner as needed. This feature enhances brand visibility and provides a customized experience for all users within the organization.

## 3️⃣  **Deactivate Account**

The **Deactivate Account** feature allows administrators to temporarily disable a user account without permanently deleting it. Once an account is deactivated, the user can no longer log in or access the platform. However, all user data, documents, permissions, and activity history are retained and can be restored if the account is reactivated in the future.
