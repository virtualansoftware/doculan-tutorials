# 🚀 Version 0.3.0 – New Enhancements

1. **PDF Scrolling** – Users can now smoothly scroll between pages in multi-page PDFs across multiple modules.
2. **Tab Navigation** – Pressing the `Tab` key moves the focus to the next field while signing.
3. **Auto-Resize Fields** – Input fields automatically expand while typing for better visibility.

---

## 1️⃣ PDF Scrolling Improvements

Users can now seamlessly scroll to the next page within PDF documents across all supported modules.  
This significantly improves the viewing and signing experience for multi-page files.

<img src="screenshots/releaseNotes/PDF_Scrolling.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="PDF Scrolling">

### Available In:
- PDF Viewer Page
- PDF eSign Page
- Signing Page
- Shared Document Page (View & Download only)

---

## 2️⃣ Enhanced Tab Navigation

You can now use the `Tab` key to move automatically to the next input field while filling or signing documents.  
This improves accessibility and speeds up the overall signing process.

<img src="screenshots/releaseNotes/TAB_Navigation.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="Tab Navigation">

### Available In:
- PDF Viewer Page
- PDF eSign Page
- Signing Page

---

## 3️⃣ Auto-Resizing Input Fields

Text-based input fields will now dynamically expand as users type, ensuring that the full value remains visible without manual resizing.

<img src="screenshots/releaseNotes/Auto-Resizing_Input_Fields.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="Auto Resizing Fields">

### Applies To:
- Text Fields  
- Email Fields  
- Number Fields  
- Initial Fields
