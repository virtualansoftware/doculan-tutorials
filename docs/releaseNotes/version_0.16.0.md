# 🚀 Version 0.16.0 – New Enhancements

## 1️⃣ **QR checkin**

Doculan now introduces **QR Check-In**, a convenient and contactless solution for managing visitor, attendee, and event registrations. Users can generate a QR code linked to a Doculan Form, allowing participants to quickly access and submit the form by scanning the QR code using their mobile device.

This provides a convenient way to securely distribute documents to clients, investors, partners, and other external stakeholders.

## 3️⃣ **Tiny URL**

The **Tiny URL** feature in Doculan provides a short, customized URL for sharing **Anonymous Forms and Anonymous VDR folders**. Instead of sharing long system-generated links, users can create a concise and easy-to-remember URL that can be shared through email, messaging applications, websites, QR codes, or other communication channels.

### 1. Tiny URL for Anonymous Forms

The **Anonymous Form Tiny URL** allows users to generate a short, customized link that can be accessed by respondents without requiring them to log in to Doculan.

## 4️⃣ **Payment Field in Form**

### New Feature

The **Payment Field** in Forms allows form creators to collect payments directly from respondents as part of the form submission process. This feature combines data collection and payment processing into a single workflow, making it easier to manage registrations, bookings, applications, and other transactions.
