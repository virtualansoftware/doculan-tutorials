# 🚀 Version 0.14.2 – New Enhancements

## 1️⃣ **Optional Hide Icons**

Introduced an option to show or **Hide text icons** across the entire form based on the required UI configuration. When enabled, the icons can display tooltips that provide additional contextual information to users.

This feature offers greater control over the form’s visual presentation, reduces unnecessary UI elements when icons are not required, and maintains the existing form behavior without impacting functionality.

## 2️⃣ **Form Description Rich Text Editor**

Introduced a **rich-text editing experience** for the Form Description section, giving users greater control over how description content is presented. A dedicated editing popup provides a clean and intuitive toolbar, allowing users to format the description without disrupting the main form layout.

The editor supports essential formatting options such as **Bold, Italic, Underline, Links, Text Alignment, Font Style, and Font Size**. Users can apply the required formatting, customize the content appearance, and review the changes before saving.

This enhancement improves the readability and presentation of form descriptions while providing a flexible and user-friendly editing experience.
