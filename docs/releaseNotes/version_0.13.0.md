# 🚀 Version 0.13.0 – New Enhancements

## 1️⃣ **Delegate Email Id In Form**

The **Delegate Email ID** feature allows **form** owners or administrators to update and reassign a form recipient after the form has been sent. This functionality is useful when the original recipient is unavailable, has provided an incorrect email address, or when responsibility needs to be transferred to another person.

Using the **Delegate Email ID** option, users can quickly replace the existing recipient with a new email address and resend the **form** without creating a new form or restarting the workflow. All form tracking, status information, and submission history remain associated with the same form process, ensuring continuity and efficient form management.

## 2️⃣ **Edit Form**

The **Edit Form** feature allows users to modify previously created forms without creating a new version from scratch. Users can update form fields, add new fields, remove unnecessary fields, modify recipient settings, and adjust form configurations as business requirements change.

This feature helps maintain form accuracy, improve data collection, and ensure that recipients always receive the most up-to-date version of the form. After making the required changes, users can save the updates and resend the form to recipients if needed.

## 3️⃣  **Conditional Field**

The **Conditional Field** feature allows **forms** to dynamically display or hide fields based on a user's response or selected values. This helps create smarter, more interactive forms by showing only relevant questions and reducing unnecessary data entry.

Conditional Fields improve the user experience by presenting fields only when specific conditions are met, ensuring accurate data collection and streamlined form completion.
