# How to Invite and Manage Team Members?

This guide provides a step-by-step overview of how to invite team members, assign roles, and manage team access in Identilan.ai, ensuring smooth collaboration and secure access control.

## Step 1: Team List

The **Team List** allows administrators to view and manage team members, review their roles and account status, and monitor security settings and user preferences.

### Key Features

- **Search Users:** Quickly find users by entering their details in the search bar.
- **Add User:** Create new user accounts by providing the required information.
- **Name & Email:** View each user's name and registered email address.
- **Role:** Identify the role assigned to each user, such as Editor or a custom role.
- **Status:** Check whether a user account is Active or Inactive.
- **MFA:** View the status of Multi-Factor Authentication for each user.
- **Preferences:** View the user's date format and time zone settings.
- **Actions:** Use the available action icons to manage user accounts, update settings, or activate and deactivate users as permitted.

## Step 2: Role Management

The **Role Management** section allows administrators to view existing roles, create custom roles, and manage module permissions based on user responsibilities.

### Key Features

- **Role Summary:** View total roles and custom roles.
- **Search Roles:** Find roles by name.
- **Create Role:** Create custom roles with specific permissions.
- **Show Details:** Review permissions assigned to each role.
- **Edit Role:** Update role settings and permissions where permitted.
- **Clone Role:** Duplicate an existing role to create a new role.
- **Delete Role:** Remove eligible custom roles when no longer needed.

### Role Action Permissions

- **Default Roles (Admin, Editor, Viewer):** Available for viewing and assignment; editing or deletion may be restricted.
- **Custom Roles:** Can be created, edited, cloned, or deleted according to administrator permissions and system restrictions.

**Note:** Assign permissions based on each user’s responsibilities and avoid granting unnecessary access.

##  Step 3: Invite a User and Assign Folder Access

The **Invite User** feature allows administrators to add team members, assign roles, and grant access to specific folders.

### Steps to Invite a User

1. Navigate to **User Management** and click **Add User**.
2. Enter the user’s **Name** and **Email Address**.
3. Select the appropriate **Role**.
4. Under **Assign Folder**, click **+ Assign Folder** and select the required folders.
5. Review the user details, role, and folder access.
6. Click **Send Invite** to send the invitation to the user.
7. Click **Cancel** to close the form without sending the invitation.

<img src=" screenshots\Team_Management\Invite_User.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="Screenshot for Document">

**Note:** Assign only the roles and folder permissions required for the user’s responsibilities.

## Step 5: Set Up Two-Factor Authentication (2FA)

Two-Factor Authentication (2FA) adds an extra layer of security to your Doculan account by requiring a verification code from an authenticator app.

### Steps to Set Up 2FA

1. **Install an Authenticator App:** Install an app such as Google Authenticator or Microsoft Authenticator.

<img src=" screenshots\Team_Management\Set_Up_2FA.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="Screenshot for Document">

2. **Generate QR Code:** Click **Generate QR Code** to display the setup code.
3. **Connect the App:** Scan the QR code or manually enter the provided secret key.

<img src=" screenshots\Team_Management\Generate_QR.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="Screenshot for Document">

4. **Verify Code:** Enter the six-digit code generated by the authenticator app.
5. **Complete Setup:** Click **Verify Code** to confirm and finish the configuration.

<img src=" screenshots\Team_Management\Verify_Code.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="Screenshot for Document">

**Note:** Keep your authenticator app and secret key secure. Never share your authentication codes with anyone.

### Two-Factor Authentication – Backup Codes

After setting up two-factor authentication (2FA), Doculan generates backup codes to help you access your account if you cannot use your authenticator app.

- **Download:** Save the backup codes securely for future use.
- **Backup Codes:** Each code can be used only once.
- **Continue:** Click **Continue** to proceed with the authentication setup.


<img src=" screenshots\Team_Management\Two_Factor_Code.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="Screenshot for Document">

**Note:** Store your backup codes in a secure location and do not share them with anyone.

## Update User

Administrators can update a user's information and assigned role.

**Procedure:**
1. Navigate to **User Management**.
2. Select **Edit User** for the required user.
3. Update the first name, email address, or role.
4. Select **Update User** to save the changes, or **Cancel/Close (X)** to discard them.

<img src=" screenshots\Team_Management\Update_User.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="Screenshot for Document">

## Deactivate User

Administrators can deactivate user accounts to restrict access without permanently deleting associated data.

**Procedure:**
1. Locate the user in **User Management**.
2. Select **Deactivate User**.
3. Enter the exact user name in the confirmation field.
4. Select **Deactivate** to confirm, or **Cancel/Close (X)** to abort.

<img src=" screenshots\Team_Management\Deactivate_User.png" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;" alt="Screenshot for Document">

**Note:** Only authorized administrators should manage user details, roles, and account status. All changes must be validated before being saved.
