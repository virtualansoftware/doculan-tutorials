# How to Create a Template?

Creating a template in **Doculan eSign** allows you to **save time** by reusing pre-defined document layouts and field placements.  
Instead of setting up each eSign from scratch, you can configure your document once and save it as a reusable template.

---

##  Overview

You can create two kinds of templates in Doculan:
- **Myself Template:** Visible only to you (for personal or one-time use)
- **Team Template:** Shared with your organization (for standardized workflows)

Templates store your field mapping, parties, and email configurations — ready to reuse anytime.

---

##  Step-by-Step: Creating a New Template

<details>
  <summary><b>Step 1: Open an existing document</b></summary>

- Navigate to your **Dashboard** and open your desired folder (e.g., “e-sign documents”).  
- Locate the document you want to use as a base for your template.  
- In the **Actions** column, click the **three-dot (⋮)** menu.  
- Select **E-Sign** to open the document in the eSign editor.

> 🖼️ **Screenshot Placeholder:** Dashboard view with “⋮ → E-Sign” option highlighted.
</details>

---

<details>
  <summary><b>Step 2: Add or verify your eSign fields</b></summary>

In the eSign editor, you’ll see three main tabs:
- **Fields**
- **Parties**
- **Template**

Click the **Fields** tab to add all necessary fields such as:
- Signature  
- Text  
- E-mail  
- Date  
- Checkbox  
- Dropdown  

Use drag-and-drop to position each field on the document.

>  Tip: You can also assign fields to specific parties (Party 1, Party 2, etc.) while adding them.
</details>

<details>
  <summary><b>Step 5: Choose template visibility</b></summary>

When saving the template, you’ll be prompted to choose between:
- **Myself** → for private use  
- **Team** → shared with all team members

1. Click **Save as Template**.  
2. A popup window appears:  
   - Template Name: *Enter a descriptive name (e.g., “Contract_Template_v1”)*  
   - Template Type: Select **Myself** or **Team**  
3. Click **Save Template**.

- In the dropdown, search for the template name you just created.  
- Select it — your saved layout should load instantly.  
- Confirm that all fields, parties, and configurations are intact.

##  Template Contents Saved

Each saved template includes:

| Component | Description |
|------------|-------------|
| Document Structure | Layout and pages of the uploaded file |
| Fields | Signature, Text, and Checkbox placements |
| Party Roles | All signer information and field assignments |
| E-mail Settings | Default subject, message, reminders |
| Template Type | “Myself” or “Team” metadata |

---

##  Example Use Case

Imagine you frequently send **Service Agreements** to new clients.

You can:
1. Upload your service agreement PDF.  
2. Add **Client Name**, **Signature**, and **Date** fields.  
3. Add Party 1 (Client) and Party 2 (You).  
4. Save it as a **Team Template** named *“Service Agreement Template”*.  
5. Now, anyone in your team can reuse it instantly.
