# How to Create Standard Review?

Standard Review is a document collaboration process that allows users to send a document to one or more reviewers for feedback before it is finalized. Reviewers can examine the document, add comments or suggestions, and submit their review. The document owner can then review the feedback, make necessary changes, and finalize the document before moving to approval or eSign. This process helps improve accuracy, streamline collaboration, and maintain document quality.

## Step 6: Reviewer Open the Document 

- Open the email and verify the document details.
- Click Review Document or the provided link to access the document.
- The document opens in review mode.
- Review the document content and provide comments or feedback, if required.
- **Viewer** — Has read-only access and can review the document content but cannot add comments or annotations.
- **Commenter** — Can review the document and add inline comments, annotations, and feedback for the sender.

**Viewer Role**

The Viewer role allows recipients to review the document, add redline suggestions, and reply to existing comments. Viewers cannot create new comments or annotations

- Viewers have read-only access to the document.
- They can open and review the document without making changes.
- Editing, commenting, and signing are not permitted.
- Viewers can access the document through the shared link or email invitation.
- Document content remains unchanged while in Viewer mode.

<img src="screenshots\Document\Document-Reviwe8.png" alt="Step 1 — Create a New Document" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;">

**Commenter Role**

The Commenter role allows recipients to review the document, add inline comments and annotations, reply to existing comments, and provide feedback through redline suggestions. This role is intended for users who need to actively participate in the document review and negotiation process.

- Commenters can view the document and add comments or suggestions.
- They cannot edit the original document content.
- Comments help provide feedback during the review process.
- Commenters can reply to or resolve comments, if permitted.
- All comments are visible to authorized participants.


<img src="screenshots\Document\Document-Reviwe9.png" alt="Step 1 — Create a New Document" style="border:2px solid black; border-radius:4px; width:100%; max-width:800px;">

## Step 7: Return Document for Revision

The Return Document for Revision feature allows reviewers to send a document back with comments or feedback for required changes After making the revisions, the document owner can update and resend the document for review.

Once the review is complete, the reviewer can return the document with all associated feedback, allowing the sender to review the proposed changes and take appropriate action.

**1.Add Comments**

The Add Comments feature allows reviewers to provide feedback, suggestions, or revision requests directly on the document. Comments help the document owner identify required changes and improve the document before final approval

- Select the text or section where you want to add a comment.
- Click Add Comment to enter your feedback.
- Provide clear and concise suggestions or revision requests.
- Save the comment to notify the document owner.
- Multiple comments can be added throughout the document.
- All comments are visible to authorized participants.

- Open and review the returned document.

## Step 9: Resend the Updated Document

Resend the updated document to the recipients after making the required changes, ensuring they receive the latest version for review or approval.

- Open the updated document.
- Review and verify all changes.
- Ensure the latest version is saved.
- Select the appropriate recipients.
- Resend the updated document.

## Step 10: Reviewer Reviews the Updated Document

The reviewer opens the updated document, verifies the revisions, reviews the latest changes, and continues the review process.

- The reviewer opens the updated document and compares it with the previous version to verify that all requested changes have been implemented accurately.

- After reviewing the revisions, the reviewer can either approve the document to proceed with the workflow or return it with additional comments for further updates.
